# Card Selling

Project workspace for a card-selling app.

## Status

The repository is initialized and ready for app development. The app requirements, framework, and hosting have not been selected yet.

## Planning the first version

Bring the requirements from the existing card-selling ChatGPT conversation into this repository. Before implementation, establish:

- Whether the app is for the seller's own workflow or for buyers too.
- The card types and information tracked for each card.
- The first essential workflow (for example, inventory, listing preparation, or sales tracking).
- Whether the first release is a web or mobile app.
- Any required marketplace integrations, accounts, or payments.

Record agreed requirements in `docs/product-plan.md` when they are available.

## Development

Clone the repository:

```sh
git clone https://github.com/metavirus/cardselling.git
cd cardselling
```

Use `codex/` branches for development and review changes through pull requests. Installation, run, and validation commands will be added when the app framework is selected.

Keep credentials and local environment files out of Git. An `.env.example` file may contain placeholder values when configuration is needed.
